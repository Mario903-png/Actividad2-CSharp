# Actividad 2 - Tabla de Amortización

Programa de consola desarrollado en C# para calcular una tabla de amortización de un préstamo con cuotas fijas.

## Tecnologías utilizadas

- C#
- .NET 10
- Spectre.Console

## Funcionalidades

El programa solicita:

- Monto del préstamo.
- Tasa de interés anual.
- Plazo en meses.

Luego calcula:

- Cuota mensual.
- Interés de cada período.
- Abono al capital.
- Saldo restante.
